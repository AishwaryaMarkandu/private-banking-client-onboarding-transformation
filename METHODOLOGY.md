# Methodology Notes

I generated the dataset synthetically with a fixed random seed so that I can reproduce the analysis.

I intentionally modelled relationships between risk, document complexity, manual touchpoints, rework and cycle time. I use these relationships to create a realistic transformation case rather than to make claims about a real bank.

I use the outputs as management-information signals. I do not interpret the synthetic figures as evidence of regulatory breaches, financial losses or actual bank performance.

I would validate the hypotheses in a real engagement using source-system data, process mining, stakeholder interviews, compliance workshops and time-and-motion analysis.
